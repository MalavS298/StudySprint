# Release Notes

Every time your squad ships something, add a short entry at the top. Newest
release goes first. Keep each entry to what a user would notice.

## Format

```
## v1.0 - YYYY-MM-DD
### Added
- Short, user-facing description of a new feature (link the ticket #).
The feature allows the user to see their past history scores. Ticket 07.
### Fixed
The past score would not append. Fixed through a different branch then merged to main.
### Changed
- Anything that behaves differently than before.
New menu option allowing user to view score history.
```
